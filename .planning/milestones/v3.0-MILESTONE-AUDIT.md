## Integration Issues

### Issue 1: `font-heading` Token Undefined (Medium)

**Impact:** Headings on GeneratingOverlay and all 4 success page states render in DM Sans instead of Libre Baskerville. Visual degradation, not a crash.

**Root cause:** Phases 16-17 used `font-heading` class but the `@theme inline` block in `globals.css` only defines `font-display` (mapped to Libre Baskerville). Naming drift between phases.

**Files affected (6 occurrences):**
- `src/app/quiz/_components/GeneratingOverlay.tsx:61`
- `src/app/quiz/success/[jobId]/page.tsx:142,177,206,243`
- `src/app/quiz/success/[jobId]/_components/SharePrompt.tsx:26`

**Fix:** Replace `font-heading` → `font-display` in all 6 locations.

**Affected requirements:** FNDN-03, GENF-03, SUCC-01

### Issue 2: Orphaned v2.0 API Routes (Low)

**Impact:** Dead code. No runtime risk since no v3.0 component calls these routes.

**Files:**
- `src/app/api/generate/route.ts` (imports `db`, dual-variant pattern)
- `src/app/api/status/[jobId]/route.ts` (imports `db`)
- `src/app/api/examples/[slug]/route.ts`

**Fix:** Delete these 3 route directories.

**Affected requirements:** FNDN-01 (spirit of old artifact removal)

  <action>
    Create `src/app/quiz/page.tsx` as a 'use client' component:

    1. **State management:**
       - `data: QuizData` initialized from `INITIAL_QUIZ_DATA`
       - `currentStep: number` starting at 0
       - `direction: number` (1=forward, -1=back) for animation direction
       - `errors: Record<string, string>` for validation display (populated by step components in Plans 02/03)

    2. **localStorage persistence:**
       - `useEffect` on mount: read from `localStorage.getItem('notevra_quiz_v1')`, parse as Partial<QuizData>, merge into data state. Wrap in try/catch.
       - `useEffect` on data change: write `JSON.stringify(data)` to `localStorage.setItem('notevra_quiz_v1')`. Wrap in try/catch.
       - Do NOT persist currentStep — on refresh, user returns to Step 1 with data pre-filled.

    3. **Navigation functions:**
       - `goNext()`: sets direction=1, increments currentStep (only if currentStep < 5)
       - `goBack()`: sets direction=-1, decrements currentStep (only if currentStep > 0)
       - `updateData(fields: Partial<QuizData>)`: merges fields into data state, clears relevant errors
       - `setStepErrors(errs: Record<string, string>)`: sets errors state

    4. **AnimatePresence layout:**
       - Import `AnimatePresence`, `motion` from 'framer-motion'
       - Import `useReducedMotion` from '@/hooks/useReducedMotion'
       - Define direction-aware variants (enter, center, exit) with custom parameter for direction
       - Wrap step content in `<div className="relative overflow-hidden min-h-[400px]">` (prevents layout shift)
       - `<AnimatePresence mode="wait" custom={direction}>` wrapping `<motion.div key={currentStep} custom={direction} variants={...}>`
       - Transition duration: 0.3s (or 0 if reducedMotion)
       - Pass `custom={direction}` to BOTH AnimatePresence AND motion.div (per research pitfall #5)

    5. **Step rendering:**
       - Define a STEPS array that maps step index to the step component
       - For now, render placeholder `<QuizCard>` for each step with titles:

         - Step 2: "What makes them special?" / "The little things that make them who they are."
         - Step 3: "Share a memory" / "A moment you'll never forget together."
         - Step 4: "Write from the heart" / "Say what you've always wanted to say."
         - Step 5: "Almost there!" / "Just a couple more details."
       - Plans 02/03 will replace these placeholders with real step components.

    6. **Page layout:**
       - Outer: `min-h-screen bg-background flex flex-col`
       - QuizProgress at top with py-8
       - Step content in flex-1 flex items-start justify-center px-4 pt-4
       - Navigation buttons at bottom: Back (left) + Next/Create My Song (right)
       - Back button hidden on Step 0
       - On Step 5, "Next" button text changes to "Create My Song" (no-op for now — Phase 16 wires generation)
       - Next button: bg-primary text-primary-foreground rounded-full px-8 py-3 font-medium
       - Back button: text-muted-foreground hover:text-foreground, with left arrow

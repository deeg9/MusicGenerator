4. Modify `goNext()` — replace the `console.log` at line 108 with `handleCreate()` call

5. Modify the render to handle generation states:

   - When `genStatus === 'error'`: show error state with:
     - The error message in `text-red-600`
     - A "Try Again" button that resets `genStatus` to `'idle'` and `genError` to `null` (returns to quiz, data preserved)
     - A note: "Your answers have been saved"
   - When `genStatus === 'idle'`: show normal quiz (existing render)

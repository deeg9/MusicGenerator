**State machine:**
- `type PageState = 'loading' | 'ready' | 'error' | 'timeout'`
- Constants: POLL_INTERVAL_MS = 2000, POLL_TIMEOUT_MS = 120_000 (2 minutes)
- State: pageState, audioUrl (string | null)

**Polling useEffect (on [jobId]):**
- `let cancelled = false` closure ref
- `const start = Date.now()`
- While loop: check timeout, fetch `/api/poll-job/${jobId}`, check status
- On COMPLETED: set audioUrl to `/api/audio/${jobId}`, set pageState to 'ready'
- On FAILED: set pageState to 'error'
- On timeout (>120s): set pageState to 'timeout'
- On catch: continue polling (transient error)
- Cleanup: set cancelled = true
- Always check `if (cancelled)` before state updates

**Download filename helper (inline):**
```typescript
function buildGiftFilename(name: string): string {
  const slug = name.toLowerCase().replace(/[^a-z0-9 ]/g, '').trim().replace(/\s+/g, '-').slice(0, 30) || 'someone-special';
  return `notevra-song-for-${slug}.mp3`;
}
```

**Create Another handler:**
```typescript
function handleCreateAnother() {
  try { localStorage.removeItem('notevra_quiz_v1'); } catch {}
  router.push('/quiz');
}
```

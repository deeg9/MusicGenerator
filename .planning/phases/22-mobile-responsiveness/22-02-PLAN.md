- iPad (768px) hits md: breakpoint — shows desktop nav, 3-col grids. Mobile-specific concerns (hamburger, 2-col grid) are iPhone SE only.
- SelectionCards use `button[aria-pressed]` selector.
- Quiz page.route() can intercept /api/quiz-generate to avoid hitting the real pod for mobile tests.
- Success page: use page.route() to mock poll-job returning a completed status with audio URL, avoiding pod dependency.
- SongPlayer play button is w-16 h-16 (64px) — already above 44px.
- Pitfall 5: iPad sees desktop layout, so iPad quiz test should verify no overflow, not test mobile-specific elements.

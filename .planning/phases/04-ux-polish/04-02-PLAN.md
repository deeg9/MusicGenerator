<task type="auto">
  <name>Task 2: Add lyrics slide animation, preserve lyrics state, and inline form validation</name>
  <files>src/components/GenerationForm.tsx</files>
  <action>
Three changes to GenerationForm:

**A. Lyrics slide-in animation (always mounted):**
- Remove the conditional `{mode === 'custom' && <LyricsTextarea ... />}` pattern
- Instead, ALWAYS render LyricsTextarea wrapped in a CSS grid container for height animation:
  ```tsx
  <div
    className="grid transition-[grid-template-rows] duration-300 ease-in-out"
    style={{ gridTemplateRows: mode === 'custom' ? '1fr' : '0fr' }}
  >
    <div className="overflow-hidden">
      <LyricsTextarea lyrics={lyrics} onChange={setLyrics} />
    </div>
  </div>
  ```
- This preserves lyrics state naturally because the component never unmounts
- The `grid-template-rows: 0fr` collapses to zero height, `1fr` expands to content height
- Add `opacity` transition as well: the inner div gets `transition-opacity duration-300` and `opacity: ${mode === 'custom' ? '1' : '0'}`

**B. Lyrics state preservation:**
- Since LyricsTextarea is always mounted, lyrics state is automatically preserved
- The `lyrics` useState already exists at the GenerationForm level — no change needed
- When submitting in simple mode, still only include lyrics in data if mode === 'custom' AND lyrics.trim() is non-empty (existing logic, keep it)

**C. Inline per-field validation:**
- Add `errors` state: `const [errors, setErrors] = useState<Record<string, string>>({});`
- Create `validate` function:
  - If `!prompt.trim()`: `errors.prompt = 'Describe your song to get started.'`
  - If `mode === 'custom' && lyrics.trim() && lyrics.length > 5000`: `errors.lyrics = 'Lyrics must be under 5000 characters.'`
  - Return errors object
- In `handleSubmit`:
  - Call `validate()` first
  - If `Object.keys(errs).length > 0`: `setErrors(errs)` and return early
  - Otherwise: `setErrors({})` and proceed with `onSubmit(data)`
- Clear individual errors on field change:
  - Prompt onChange: `setErrors(prev => { const {prompt, ...rest} = prev; return rest; })`
  - Lyrics onChange: `setErrors(prev => { const {lyrics, ...rest} = prev; return rest; })`
- Render error messages below each field:
  ```tsx
  {errors.prompt && <p className="mt-1 text-xs text-destructive">{errors.prompt}</p>}
  ```
- Also add `aria-invalid={!!errors.prompt}` to the prompt input for accessibility
- Add `ring-destructive` to input border when error is present
  </action>

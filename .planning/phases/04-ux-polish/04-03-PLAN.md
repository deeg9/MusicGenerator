**A. Create `src/app/api/examples/[slug]/route.ts`** following the /api/audio/[key] pattern:
- Define a hardcoded slug-to-R2-key map:
  ```typescript
  const EXAMPLE_KEYS: Record<string, string> = {
    'jazz-birthday': 'examples/jazz-birthday.mp3',
    'love-ballad': 'examples/love-ballad.mp3',
    'graduation': 'examples/graduation.mp3',
  };
  ```
- GET handler:
  1. Extract `slug` from params (await params like in /api/audio)
  2. Look up `EXAMPLE_KEYS[slug]` — if not found, return 404 with `{ error: { category: 'invalid_input', retryable: false, message: 'Example not found.' } }`
  3. Call `getAudioPresignedUrl(r2Key, 3600)` from `@/lib/r2`
  4. Return `NextResponse.json({ url, expiresIn: 3600 })`
  5. Wrap in try/catch, return 500 on R2 errors using `classifyError` from `@/lib/errors`
- This is a thin route (~40 lines) — slug acts as a safe indirection so R2 keys are not exposed to the client

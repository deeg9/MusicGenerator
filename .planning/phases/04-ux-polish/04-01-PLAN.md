  <name>Task 2: Refactor GenerationPage with state machine and inline error banners</name>
  <files>src/components/GenerationPage.tsx, src/components/GenerationResults.tsx</files>
  <action>
1. **Refactor `src/components/GenerationPage.tsx`** to use a unified phase state machine:
   - Add type: `type GenerationPhase = 'idle' | 'submitting' | 'polling' | 'done' | 'error';`
   - Replace `isSubmitting` boolean with `phase` state: `const [phase, setPhase] = useState<GenerationPhase>('idle');`
   - Add `errorMessage` and `isRetryable` state
   - Add `stageIndex` state and `lastFormData` ref (for retry)
   - Add `useEffect` for stage progression when `phase === 'polling'`:
     - Reset stageIndex to 0 immediately
     - Set timeouts: after 1500ms -> stage 1, after 5500ms -> stage 2
     - Clean up timers on phase change or unmount
   - **handleSubmit changes:**
     - Set `phase = 'submitting'` at start, clear previous error/jobId
     - Store form data in `lastFormData` ref for retry
     - On API error: set `phase = 'error'`, `errorMessage`, `isRetryable = false`
     - On network error: set `phase = 'error'`, `errorMessage = 'Network error...'`, `isRetryable = true`
     - On success: set `jobId`, then `phase = 'polling'`
     - Remove all `alert()` calls
   - **Watch useGenerationStatus results** via useEffect:
     - When `data?.status === 'completed'`: set `phase = 'done'`
     - When `data?.status === 'failed'`: set `phase = 'error'`, pull message from `data.error?.message`, `isRetryable = data.error?.retryable ?? true`
     - When hook `error` is truthy: set `phase = 'error'`
   - **handleRetry function:** Call `handleSubmit(lastFormData.current)` to re-submit same data
   - **JSX restructure — conditional rendering based on phase:**
     - `phase === 'idle'`: Show GenerationForm (pass `isSubmitting={false}`)
     - `phase === 'submitting'`: Show LoadingAnimation with stageIndex=0 (form hidden)
     - `phase === 'polling'`: Show LoadingAnimation with current stageIndex + elapsedSeconds from hook
     - `phase === 'done'`: Show GenerationResults (pass jobId, enhancedCaption)
     - `phase === 'error'`: Show inline error banner with message + retry/back-to-form button
   - **Error banner JSX:** `rounded-lg border border-destructive/50 bg-destructive/10 px-4 py-3` with error message and conditional retry button (retryable -> "Try again" calls handleRetry, non-retryable -> "Change settings" sets phase to 'idle')
   - Keep the header (h1 + subtitle) always visible
   - Keep URL persistence logic for jobId (router.replace)
   - If page loads with `?job=` param, set `phase = 'polling'` initially (or check if already completed)

2. **Simplify `src/components/GenerationResults.tsx`**:
   - Remove the polling/loading state UI (the `isPolling &&` block) — loading is now handled by GenerationPage
   - Remove the error display blocks — errors are now handled by GenerationPage
   - Keep only: enhanced caption display + variant cards grid for completed results
   - The component now only renders when phase==='done', so it can assume data is completed
   - Still receive and use `useGenerationStatus` hook internally to get the data, OR receive data as a prop. Prefer keeping the hook internally for consistency — GenerationPage sets phase='done' when hook reports completed, then GenerationResults renders with the same jobId and the hook will return completed data.

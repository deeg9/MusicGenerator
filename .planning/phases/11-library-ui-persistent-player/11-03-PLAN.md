       - Add imports: `import { useRef } from 'react'` (if not already), `import { useGSAP } from '@gsap/react'`, `import { gsap } from '@/lib/gsap-config'`
       - Add `cardRef = useRef<HTMLDivElement>(null)` for the outer card div (use as scope for useGSAP)
       - Add `titleRef = useRef<HTMLSpanElement>(null)` on the title text span
       - Call `const { contextSafe } = useGSAP({ scope: cardRef })` — scope constrains GSAP to this card's DOM
       - Create `handleMouseEnter` using contextSafe wrapper:
         ```
         const handleMouseEnter = contextSafe(() => {
           if (!titleRef.current) return;
           gsap.to(titleRef.current, {
             duration: 0.75,
             scrambleText: {
               text: title,
               chars: '\u266A\u266B\u2669\u266C\u266D\u266E\u266F abcdefghijklmnopqrstuvwxyz',
               speed: 0.4,
               revealDelay: 0.1,
             },
           });
         });
         ```
         Where title = deriveTitle(song.promptText)
         chars string uses Unicode escapes for music symbols: ♪♫♩♬♭♮♯ mixed with space and lowercase letters
       - Attach `ref={cardRef}` to the outer card div
       - Attach `onMouseEnter={handleMouseEnter}` to the outer card div
       - Attach `ref={titleRef}` to the title `<span>` element

    IMPORTANT:
    - Import gsap ONLY from '@/lib/gsap-config' (project decision — never from 'gsap' directly)
    - contextSafe is CRITICAL — without it, hover-triggered tweens are not tracked by GSAP context and will leak on unmount
    - The scramble triggers on every mouseenter (not once) because gsap.to creates a new tween each time
    - No special mobile handling needed — onMouseEnter naturally does not fire on touch devices
    - Duration 0.75s per user decision (0.7-0.8 range)

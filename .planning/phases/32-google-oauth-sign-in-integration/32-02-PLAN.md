  <name>Task 1: Configure Google Cloud Console and Supabase Dashboard</name>
  <files>N/A - external dashboard configuration only</files>
  <action>
The user must complete these steps manually. Claude cannot access external dashboards.

**Google Cloud Console (https://console.cloud.google.com):**

1. Go to APIs and Services -> Credentials
2. Click "Create Credentials" -> "OAuth 2.0 Client ID"
3. Application type: Web application
4. Name: "Notevra" (or any descriptive name)
5. Authorized JavaScript origins: `http://localhost:3000`
6. Authorized redirect URIs: `https://aiypybffzqgmerkjehfn.supabase.co/auth/v1/callback`
7. Click "Create" and copy the Client ID and Client Secret

**Supabase Dashboard (https://supabase.com/dashboard):**

1. Go to Authentication -> Providers -> Google
2. Toggle Google provider ON
3. Paste Client ID and Client Secret from Google Cloud Console
4. Note: The "Callback URL (for OAuth)" shown here should match what you entered in Google Cloud Console redirect URIs
5. Go to Authentication -> URL Configuration -> Redirect URLs
6. Add: `http://localhost:3000/**` (if not already present)
7. Save

Create `src/app/api/send-creator-email/route.ts`:

```typescript
export async function POST(request: NextRequest): Promise<NextResponse>
```

**Flow:**
1. Parse JSON body, validate `songId` (string, required) — return 400 if missing
2. Query song via Drizzle `db`: `db.select().from(songs).where(eq(songs.id, songId)).limit(1)`
   - Return 404 if no song found
   - Return 400 if `song.userId` is null (anonymous songs have no creator email)
   - Return 400 if `song.r2Mp3Key` is null (song not finalized)
3. Look up creator email via Supabase admin client:
   ```typescript
   const supabaseAdmin = createClient(
     process.env.NEXT_PUBLIC_SUPABASE_URL!,
     process.env.SUPABASE_SERVICE_ROLE_KEY!
   );
   const { data: { user } } = await supabaseAdmin.auth.admin.getUserById(song.userId);
   ```
   - Return 500 if user lookup fails or email is null
4. Generate presigned URLs:
   - `listenUrl`: `getAudioPresignedUrl(song.r2Mp3Key, 86400)` — 24h for creator
   - `downloadUrl`: `getAudioPresignedUrl(song.r2Mp3Key, 86400, `${song.recipientName}-song.mp3`)` — with Content-Disposition filename
5. Send email:
   ```typescript
   const { data, error } = await resend.emails.send({
     from: 'Notevra <hello@notevra.com>',
     to: [user.email],
     subject: `Your song for ${song.recipientName} is ready`,
     react: SongReadyEmail({ recipientName: song.recipientName, listenUrl, downloadUrl, genre: song.genre }),
   });
   ```
6. Return `{ id: data.id }` on success, `{ error }` with 500 on failure

**Important:** Use Drizzle `db` for song lookup (postgres role bypasses RLS). Use Supabase admin client (service role key) for auth.users email lookup. Import `createClient` from `@supabase/supabase-js` directly (not the SSR wrapper).

Then create the test file. Mock `@/db` (db.select chain), `@/lib/resend` (resend.emails.send), `@/lib/r2` (getAudioPresignedUrl), and `@supabase/supabase-js` (createClient). Use `vi.mock()` with `vi.hoisted()` for mock variables per project convention (Phase 29 decision).

Create `src/app/api/send-recipient-email/route.ts`:

```typescript
export async function POST(request: NextRequest): Promise<NextResponse>
```

**Flow:**
1. Parse JSON body, validate `songId` (string, required) and `recipientEmail` (string, required) — return 400 if either missing
2. Query song via Drizzle `db`: same pattern as send-creator-email
   - Return 404 if no song found
   - Return 400 if `song.r2Mp3Key` is null (song not finalized)
3. Extract creator context:
   - `creatorFirstName`: If song has `userId`, look up via Supabase admin client and extract first name from `user.user_metadata.full_name` or email prefix. If anonymous song, use "Someone" as fallback.
   - `message`: `(song.quizData as any)?.message || ''`
   - `relationship`: `song.relationship`
   - `genre`: `song.genre`
   - `recipientName`: `song.recipientName`
4. Generate presigned URL:
   - `listenUrl`: `getAudioPresignedUrl(song.r2Mp3Key, 604800)` — 7-day maximum (R2 hard cap). DO NOT attempt longer expiry.
5. Send email:
   ```typescript
   const { data, error } = await resend.emails.send({
     from: 'Notevra <hello@notevra.com>',
     to: [recipientEmail],
     subject: `${creatorFirstName} made something just for you`,
     react: GiftDeliveryEmail({
       recipientName: song.recipientName,
       creatorFirstName,
       relationship: song.relationship,
       message,
       genre: song.genre,
       listenUrl,
     }),
   });
   ```
6. Return `{ id: data.id }` on success, `{ error }` with 500 on failure

**Note:** This route does NOT require authentication — the creator on the success page may be anonymous. The songId + recipientEmail are the authorization tokens. The presigned URL expires in 7 days (R2 maximum).

Then create the test file. Same mocking approach as Task 1. Pay special attention to testing the 604800-second presigned URL expiry — this is a critical constraint.

Create `e2e/pages/` directory and build three POM classes plus a shared fixtures file.

**e2e/pages/landing.ts — LandingPage POM:**
- Constructor takes `Page`, stores as `readonly page`
- Locator properties: `heroHeading` (getByRole heading with /turn your feelings into a song/i), `heroCtaButton` (getByRole link /create your song/i .first()), `navCreateButton` (getByRole link /create your song/i .nth(1)), `howItWorksSection` (locator '#how-it-works'), nav links for 'How it Works', 'Examples', 'Reviews' (getByRole link with exact name)
- Method: `goto()` navigates to '/'

**e2e/pages/quiz.ts — QuizPage POM:**
- Constructor takes `Page`
- Navigation locators: `nextButton` (getByRole button /next/i), `backButton` (getByRole button /back/i), `createSongButton` (getByRole button /create my song/i)
- Step 1: `step1NameInput` (getByPlaceholder 'Their first name')
- Steps 3-5 textareas: `step3TextArea` (getByPlaceholder /kind, patient/i), `step4TextArea` (getByPlaceholder /got lost driving/i), `step5TextArea` (getByPlaceholder /I don't say it enough/i)
- Step 6: `step6LanguageSelect` (getByRole combobox), `step6EmailInput` (getByPlaceholder 'your@email.com')
- Error: `errorAlert` (getByRole alert)
- Methods: `goto()` navigates to '/quiz', `selectOption(label: string)` clicks button by exact name, `clickNext()`, `clickBack()`, `getStepHeading(text: string)` returns locator for heading with given name
- IMPORTANT: Do NOT define `nextOrCreateButton` — keep them separate so specs are explicit about which step they're on. On step 5 (last step), the button says "Create My Song" not "Next".

- Method: `goto(jobId: string, name?: string)` navigates to `/quiz/success/${jobId}?name=${encodeURIComponent(name)}`

  <action>
**1. Modify `src/app/layout.tsx`:**
- Make the default export an `async` function (it is already a Server Component)
- Import `createClient` from `@/lib/supabase/server`
- At the top of the function body, create Supabase client and get user:
  ```
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()
  ```
- Pass `user` prop to Header: `<Header user={user} />`
- Keep everything else (fonts, metadata, Footer, main) unchanged

**2. Convert `src/components/Header.tsx` to a Server Component:**
- Remove `'use client'` directive
- Remove `useState` import and `mobileMenuOpen` state
- Import `HeaderClient` from `./HeaderClient`
- Import `User` type from `@supabase/supabase-js`
- Accept `{ user }: { user: User | null }` prop
- Render `<HeaderClient user={user} />` — delegate ALL interactivity
- This is a thin wrapper — its purpose is to be importable as a Server Component

**3. Create `src/components/HeaderClient.tsx` as the Client Component:**
- Add `'use client'` directive
- Import `User` type from `@supabase/supabase-js`
- Move ALL existing Header JSX and state here (useState for mobileMenuOpen)
- Accept `{ user }: { user: User | null }` prop
- Add new state: `const [dropdownOpen, setDropdownOpen] = useState(false)`

**Desktop nav area (after existing nav links, before CTA):**
- When `!user` (anonymous): Add two text links:
  - "Sign Up" → `/signup` (styled as `text-sm font-medium text-muted-foreground hover:text-foreground`)
  - "Log In" → `/login` (same style)
- When `user` (authenticated): Add avatar dropdown:
  - Trigger: Circle with user initial (`user.email?.[0]?.toUpperCase() || 'U'`), styled as `h-8 w-8 rounded-full bg-primary text-primary-foreground text-xs font-bold flex items-center justify-center cursor-pointer` (mirrors the Notevra "N" logo circle pattern per user decision)
  - Dropdown panel: absolute positioned below avatar, `bg-white rounded-lg shadow-lg border border-border/40 py-1 min-w-[160px]`
  - Dropdown items:
    - "My Songs" → `/dashboard` (Link)
    - Divider: `border-t border-border/40 my-1`
    - "Sign Out" → calls `signOut` server action from `@/app/login/actions` (use a `<form action={signOut}>` pattern or import and call in onClick with `startTransition`)
  - Close dropdown on click outside (useEffect with document click listener) and on Escape key

**"Create Your Song" CTA stays visible for ALL users** — do not move or conditionally render it

**Mobile hamburger drawer (below existing nav links):**
- When `!user`: Add "Sign Up" and "Log In" links at the bottom of the drawer nav
- When `user`: Add "My Songs" link and "Sign Out" button at the bottom of the drawer nav
- Close drawer on any link click (existing pattern: `onClick={() => setMobileMenuOpen(false)}`)

**Sign-out implementation:**
- Import `signOut` from `@/app/login/actions` (it lives alongside login since it's a global auth action)
- The `signOut` server action (already exists from Plan 02's login/actions.ts) calls `supabase.auth.signOut()`, `revalidatePath('/', 'layout')`, and `redirect('/')`
- If Plan 02 hasn't added `signOut` to login/actions.ts yet, add it here: export a `signOut` server action in `src/app/login/actions.ts` that calls `supabase.auth.signOut()`, `revalidatePath('/', 'layout')`, `redirect('/')`

   - Write WAV to temp file (`os.tmpdir()` + unique name with `Date.now()` + random suffix)
   - Run ffmpeg via `child_process.execFile` (promisified) with args: `-i tmpIn -codec:a libmp3lame -b:a 320k -y tmpOut`

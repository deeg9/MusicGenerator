  <action>
Create `src/components/GenerationForm.tsx` with `'use client'` directive (uses useState, event handlers).

```typescript
interface GenerationFormData {
  prompt: string;
  lyrics?: string;
  genreTags?: string;
  duration: number;
  instrumental: boolean;
}

interface GenerationFormProps {
  onSubmit: (data: GenerationFormData) => void;
  isSubmitting: boolean;
}
```

**State management (useState for each field):**
- `mode: 'simple' | 'custom'` — default `'simple'`
- `prompt: string` — default `''`
- `selectedGenres: string[]` — default `[]`
- `customGenreText: string` — default `''`
- `duration: number` — default `120` (Standard)
- `instrumental: boolean` — default `false`
- `lyrics: string` — default `''`

**Layout (top to bottom):**
1. ModeToggle (Simple / Custom)
2. Text prompt input — `<input type="text">` with placeholder "Describe the vibe of your song..." (always visible in both modes)
   - Styled: `w-full bg-zinc-900 border border-zinc-700 rounded-lg px-4 py-3 text-zinc-200`
   - Section label: "Describe your song"
3. LyricsTextarea — ONLY visible when `mode === 'custom'`. Preserve lyrics state when toggled away (per RESEARCH.md Open Question 3).
4. GenreChips — always visible in both modes
5. DurationPreset — always visible
6. Instrumental toggle — a simple labeled checkbox or toggle switch
   - Label: "Instrumental (no vocals)"
   - Use a styled checkbox or a small toggle. Keep it simple: `<label>` wrapping `<input type="checkbox">` with Tailwind styling.
7. Submit button — "Generate Song" (or "Generating..." when `isSubmitting`)
   - Full width, `bg-violet-600 hover:bg-violet-500 text-white font-medium py-3 rounded-lg transition-colors`
   - Disabled when `isSubmitting` or `prompt` is empty
   - Show `disabled:opacity-50 disabled:cursor-not-allowed` when disabled

**onSubmit handler:**
- Prevent default form submission
- Combine `selectedGenres` array and `customGenreText` into a single comma-separated `genreTags` string: `[...selectedGenres, ...customGenreText.split(',').map(s => s.trim())].filter(Boolean).join(', ')`
- Only include `lyrics` in the data if `mode === 'custom'` and lyrics is non-empty
- Call `props.onSubmit(data)`

**Overall form styling:**
- Container: `flex flex-col gap-6` with some padding
- Dark theme consistent with existing app: zinc-900/zinc-950 backgrounds, zinc-700 borders, violet-600 accents

Do NOT add any fetch calls or API logic. The form only calls the `onSubmit` prop with structured data.

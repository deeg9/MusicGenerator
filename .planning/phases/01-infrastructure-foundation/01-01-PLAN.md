<task type="auto">
  <name>Task 2: Create RunPod client, R2 client, and error classification modules</name>
  <files>
    src/lib/runpod.ts
    src/lib/r2.ts
    src/lib/errors.ts
  </files>
  <action>
    1. Create `src/lib/runpod.ts` -- ACE-Step API client:
       - Import `env` from `@/env`
       - `submitGenerationJob(params)`: POST to `${env.RUNPOD_URL}/release_task` with body: { prompt, lyrics, audio_duration, batch_size: 2 }. Optional params: bpm, key_scale, time_signature, seed. Returns { task_id: string }.
       - `queryJobStatus(taskId)`: POST to `${env.RUNPOD_URL}/query_result` with body: { task_id_list: [taskId] }. Returns parsed response with status (0=running, 1=succeeded, 2=failed), data (audio_urls array), error.
       - `fetchAudioBuffer(audioPath)`: GET to `${env.RUNPOD_URL}${audioPath}` to download the actual audio file from the ACE-Step server. Returns Buffer. This is needed because audio_urls in the response are relative paths on the ACE-Step server.
       - Type definitions for all params and responses (TypeScript interfaces, not `any`)
       - Timeout on fetch calls: 90 seconds for job queries (per research recommendation), 30 seconds for audio download
       - Use AbortController for timeout implementation

    2. Create `src/lib/r2.ts` -- Cloudflare R2 client:
       - Import `env` from `@/env`
       - Create S3Client singleton: region 'auto', endpoint `https://${env.CLOUDFLARE_ACCOUNT_ID}.r2.cloudflarestorage.com`, credentials from env
       - `uploadAudioToR2(key: string, buffer: Buffer): Promise<void>` -- PutObjectCommand with ContentType 'audio/wav'
       - `getAudioPresignedUrl(key: string, expiresIn?: number): Promise<string>` -- getSignedUrl with GetObjectCommand, default 1 hour expiry
       - `buildR2Key(generationId: string, variantIndex: number): string` -- returns `generations/${generationId}/output_${variantIndex}.wav`
       - Export all functions and the key builder

    3. Create `src/lib/errors.ts` -- Error classification with dual-layer responses:
       - Define `ErrorCategory` type: 'model_error' | 'timeout' | 'gpu_unavailable' | 'invalid_input' | 'rate_limited' | 'unknown'
       - Define `GenerationError` interface: { category: ErrorCategory, retryable: boolean, userMessage: string, technicalMessage: string }
       - `classifyError(rawError: unknown): GenerationError` function that maps:
         - Timeout/AbortError -> category 'timeout', retryable true, user message "Generation timed out. The GPU may be busy -- please try again."
         - Network/fetch errors -> category 'gpu_unavailable', retryable true, user message "The generation server is temporarily unavailable. Please try again in a moment."
         - ACE-Step status=2 errors -> category 'model_error', retryable true, user message "The AI model encountered an error generating your song. Please try again."
         - Input validation errors -> category 'invalid_input', retryable false, user message describing what's wrong
         - All others -> category 'unknown', retryable true, user message "Something went wrong. Please try again."
       - `toErrorResponse(error: GenerationError)`: Returns JSON-safe object with both layers (technical for logging, user-facing for display)
       - Per user decision: NO auto-retry server-side. Errors returned immediately for user to decide.
  </action>
  <verify>

    - `src/lib/errors.ts` classifyError handles at minimum: timeout, network failure, model error, invalid input, and unknown cases

  <action>
1. Install packages:
   ```
   npm install -D @playwright/test @next/bundle-analyzer
   npx playwright install chromium
   ```

2. Create `playwright.config.ts` at project root using the RESEARCH.md "Full playwright.config.ts" pattern exactly:
   - testDir: './e2e'
   - timeout: 30_000 (default — generation tests override per-test)
   - fullyParallel: true
   - forbidOnly: !!process.env.CI
   - retries: process.env.CI ? 2 : 0
   - workers: process.env.CI ? 1 : undefined
   - reporter: [['html', { outputFolder: 'playwright-report', open: 'never' }]]
   - use.baseURL: 'http://localhost:3000'
   - use.trace: 'on-first-retry'
   - use.screenshot: 'only-on-failure'
   - use.contextOptions.reducedMotion: 'reduce' (disables Framer Motion animations)
   - Three projects: 'chromium' (Desktop Chrome), 'mobile-iphone' (iPhone SE), 'mobile-ipad' (iPad)
   - webServer: command 'npm run dev', url 'http://localhost:3000', reuseExistingServer: !process.env.CI, timeout: 120_000, stdout: 'ignore', stderr: 'pipe'
   - globalSetup: require.resolve('./e2e/global-setup')

3. Create `e2e/global-setup.ts` using the RESEARCH.md pattern:
   - Import dotenv, load `.env.local` with explicit path: `dotenv.config({ path: path.resolve(process.cwd(), '.env.local') })`
   - Read HEARTMULA_URL from process.env
   - If not set, warn and set POD_AVAILABLE='false'
   - If set, fetch the pod root URL with 10-second AbortController timeout
   - Any HTTP response (including 404) = pod reachable, set POD_AVAILABLE='true'
   - Network error / timeout = pod unreachable, set POD_AVAILABLE='false' with warning
   - Log the result clearly

4. Create `e2e/tsconfig.json`:
   - extends: "../tsconfig.json"
   - compilerOptions.moduleResolution: "node" (override from "bundler" — required for Node.js context)
   - compilerOptions.baseUrl: ".."
   - compilerOptions.paths: { "@/*": ["./src/*"] }
   - include: ["./**/*.ts"]

5. Create `e2e/smoke.spec.ts` — minimal test to prove the harness works:
   ```typescript
   import { test, expect } from '@playwright/test';

   test('app loads at root', async ({ page }) => {
     await page.goto('/');
     await expect(page).not.toHaveTitle(/error/i);
   });
   ```

6. Update `package.json` scripts — ADD these four scripts (keep existing dev/build/start/lint):
   - "test:e2e": "playwright test --project=chromium"
   - "test:e2e:headed": "playwright test --project=chromium --headed"
   - "test:unit": "vitest run"
   - "analyze": "ANALYZE=true next build"

   Note: default test:e2e runs only chromium project. Mobile projects are defined but run explicitly in Phase 22.

7. Update `next.config.ts` to wrap with bundle analyzer:
   ```typescript
   import type { NextConfig } from "next";
   import BundleAnalyzer from '@next/bundle-analyzer';

   const withBundleAnalyzer = BundleAnalyzer({
     enabled: process.env.ANALYZE === 'true',
   });

   const nextConfig: NextConfig = {
     serverExternalPackages: ['ffmpeg-static'],
   };

   export default withBundleAnalyzer(nextConfig);
   ```

8. Append to `.gitignore`:

## Tech Debt

### Phase 21: Happy Path & Error State E2E

- **E2E-05 human verification pending:** Test code is correct and fully wired. Full funnel traversal succeeded during automated verification. The A40 pod was reachable but exceeded the 90s timeout for generation completion. Needs a human-triggered run when the pod is at normal latency (~7-30s).
- **E2E-05 CI coverage gap:** Test skips cleanly when `HEARTMULA_URL` is absent (by design). In CI, the happy path will never run unless the RunPod URL is injected as a CI secret. This is an operational gap, not a code bug.

### Phase 23: Performance Audit & Optimization

- **`npm run analyze` script missing `--webpack` flag:** The script `ANALYZE=true next build` silently produces no analyzer report when Next.js defaults to Turbopack. Should be `ANALYZE=true next build --webpack`. One-word fix.
- **PERF-04 mobile simulation:** Lighthouse localhost mobile simulation showed LCP 3212ms (throttling artifact). Real browser measurement via Playwright confirmed Desktop LCP 80ms, Mobile LCP 348ms, CLS 0.0000/0.0811 — all pass thresholds. Human approved.
